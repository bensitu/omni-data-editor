# OmniDataEditor

OmniDataEditor is a framework independent TypeScript editing engine. It manages entity drafts, validation, asynchronous persistence and concurrent changes. Presentations bind native controls to sessions; hosts connect existing UI libraries through focused capabilities.

Start with the [usage guide](./guide/getting-started.md), try the [interactive playground](./guide/playground.md), or explore [headless editing](./guide/standalone.md). The source repository includes a team directory playground and six focused examples for standalone, DataTables, Tabulator and asynchronous selection.

Packages use ESM exports and explicit stylesheet imports. JavaScript entry points can be imported in server environments; rendering browser controls requires a browser.

See [compatibility](./support.md), [accessibility](./accessibility.md) and [security](./security.md) for integration requirements.
