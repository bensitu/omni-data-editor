# @omnidataeditor/dom

## 0.1.1

### Patch Changes

- Expose optional bulk canonical update reflection for host integrations.

- Preserve numeric input spelling, interpolate issue parameters, and safely resolve catalog keys.
- Keep conflict actions available with silent notifications and retain unknown-result feedback.

- Validate presentation field configuration before creating controls.
- Write cleared numeric and select values to drafts, share batch predicate values, and delegate required-state updates to renderers.
- Localize control and form messages and handle asynchronous submit failures.
