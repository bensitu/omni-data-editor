# @omnidataeditor/dom

Native controls, renderer registration, forms and focus capabilities.

```ts
import { createRendererRegistry, createEditorForm } from '@omnidataeditor/dom';
```

Register extension renderers with scoped keys. Raw input belongs to controls; parsed semantic values enter sessions.

Part of OmniDataEditor. ESM distribution under the MIT license. See the [documentation](https://bensitu.github.io/omni-data-editor/) and [renderer guide](https://bensitu.github.io/omni-data-editor/guide/custom-renderer).
