# @omnidataeditor/theme-default

Default theme properties and low specificity styles.

```ts
import '@omnidataeditor/theme-default/styles.css';
```

Styles are an explicit client import. JavaScript entry points never import CSS on the server. Override the omnidataeditor CSS custom properties to theme controls.

Part of OmniDataEditor. ESM distribution under the MIT license. See the [documentation](https://bensitu.github.io/omni-data-editor/) and [stylesheet installation](https://bensitu.github.io/omni-data-editor/guide/getting-started).
