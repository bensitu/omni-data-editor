# @omnidataeditor/presentation-dialog

Native modal dialog presentation for editing sessions.

```ts
import { dialog } from '@omnidataeditor/presentation-dialog';
editor.use(dialog({ fields, title: 'Edit entity' }));
```

Pass the registered field definitions and optional renderer registry. Dialog rendering requires a browser.
