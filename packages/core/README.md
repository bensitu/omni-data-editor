# @omnidataeditor/core

Headless entity editing, validation, changes, persistence and reconciliation.

```ts
import { createEditor, textField } from '@omnidataeditor/core';
```

Core has zero runtime dependencies and compiles without browser libraries. Entity values and field writers follow immutable semantics.

Part of OmniDataEditor. ESM distribution under the MIT license. See the [documentation](https://bensitu.github.io/omni-data-editor/) and [headless editing guide](https://bensitu.github.io/omni-data-editor/guide/standalone).
