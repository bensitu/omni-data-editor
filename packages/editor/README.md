# @omnidataeditor/editor

Common OmniDataEditor factories and types.

```sh
pnpm add @omnidataeditor/editor @omnidataeditor/theme-default
```

```ts
import {
  createEditor,
  textField,
  dialog,
  inline,
} from '@omnidataeditor/editor';
import '@omnidataeditor/theme-default/styles.css';
```

Host integrations and asynchronous selection are separate optional packages. The facade contains no independent runtime.
