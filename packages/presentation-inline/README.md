# @omnidataeditor/presentation-inline

Anchored editing with explicit focus boundary behavior.

```ts
import { inline } from '@omnidataeditor/presentation-inline';
editor.use(inline({ fields, fieldId: 'name' }));
```

Hosts provide anchors and focus. Viewport reveal is optional unless explicitly required. Blur has no automatic action by default.
